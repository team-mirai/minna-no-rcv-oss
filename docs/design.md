# みんなのRCV 設計メモ

「調整さん」のように、誰でもアカウントなしで RCV（優先順位付投票 / 即時決選）を開催できる
無料ツールの設計メモ。実装の判断理由は各ファイルのコメントにも書いてある。

## 1. ユーザー像（ペルソナ4）
1. コミュニティ / イベント幹事（懇親会の会場、LT のテーマ決め）
2. 職場チーム（施策の優先順位、ロゴ案）
3. 学校・自治会・NPO（役割・企画の合意形成）
4. 政治・行政文脈の実践者（住民ワークショップ等）

## 2. 価値仮説の芯
票割れ解消 × 「並べるだけ」の UI × **開票のドラマが共有されて次の主催者を生む**ループ
（結果ページ → 新規作成 がコア指標）。差別化＝日本語カジュアル RCV の空白＋開票プレゼン演出。

## 3. ユーザージャーニー
作成者：お題と選択肢を入れて作成 → 参加URL と 管理URL を受け取る → 参加URLを配る → 締め切る → 結果を共有。
参加者：URL を開く → 候補を1位から並べる（全部でなくてもOK）→ 投票（受付中は何度でも変更）→ 結果を見る。

## 4. 画面
- `/`：ランディング（RCV の説明＋作成導線）
- `/new`：作成フォーム
- `/p/<slug>`：参加（順位付け）
- `/p/<slug>/results`：結果（開票の経過つき。受付中は show_live_count 次第で途中経過）
- `/p/<slug>/manage?key=…`：管理（共有URL・締切・結果公開）

## 5. データモデル
`poll(slug, status open|closed, close_at, results_open_at, require_captcha, show_live_count, admin_key_hash)` /
`poll_option(poll_id, label, color, sort_order)` /
`ballot(pk=(poll_id, voter_key), rankings uuid[])` /
`poll_result(poll_id, result jsonb, ballot_count)` /
`submit_log`（追記専用・荒らし事後フィルタ用）。

**poll ごとに完全独立**で、「いま開催中の投票はどれか」のようなグローバル状態を持たない。
これが汎用ツールとしての本質的な単純化で、「選択肢ゼロの投票が残り得る」「開催中は常に1件、
をアプリ側のループで維持する」といった一群の問題がまとめて消える。

## 6. 信頼モデル（3階層・正直に明示）
- **L0 browser_key**（既定・調整さんと同水準）：サーバ発行 Cookie による 1ブラウザ1票。本人性は非保証。
- **L1 Turnstile（任意）＋ IP レート制限**：`require_captcha` で有効化（現状は seam のみで未実装）。
- **L2 1人1URL の名簿モード（将来）**：招待制。
- 「正式な選挙・議決には使えない」を常設表記。UGC リスク対策（一覧/検索なし＋通報＋規約）は
  一般公開の条件。

## 7. 投票受理の atomic 性（設計の核）

満たしたい性質は 2 つ。

- **締切がコミットした後の票は、絶対に入らない**
- **結果は締切後の不変データから計算され、何度計算しても同じになる**

素直に書くと「status を SELECT → 選択肢を SELECT → upsert」の 3 往復・3 トランザクションに
なり、締切とレースする（検証した瞬間と書き込む瞬間の間に締切が入り得る）。ここを
**DB の行ロックだけ**で構造的に解いている（advisory lock も Redis も要らない）。

- `submit_ballot` 単一 RPC … `poll` 行を `FOR SHARE` で読み、検証と upsert を同一 tx に閉じる。
  submit 同士は `FOR SHARE` なのでブロックし合わず、高並行に耐える。
- `close_poll` の `UPDATE` … 行の排他ロックを取るので、進行中の受理がコミットするまで待ってから
  `closed` にする。締切コミット後の受理は `FOR SHARE` で `closed` を読んで弾かれる。
- 集計は締切後の不変データにのみ実行し、`poll_result` にスナップショットする
  （`tallyRcv` は決定的なので冪等）。

## 8. 汎用化のために落としたもの
members / eligibility / マジックリンク / pepper（議決系）/ 設定トグル群 / イベント実行の概念 /
管理者共有パスワード / CSV import / リアクション。
→ グローバル状態ゼロ・poll ごと独立が本質。
